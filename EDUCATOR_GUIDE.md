# Educator guide

## Objectives and prerequisites
For approximately age 15; suggested 10–15 minutes. Learners should be comfortable reading percentages/means and simple scatterplots. Objectives: explain how framing affects visual impression without changing values, identify a sampling limitation, distinguish association from causal evidence, and assemble a cautious claim supported by an observation and limitation.

## Synthetic data provenance and dictionary
Every organisation/headline is fictional and every value is generated for this lesson; nothing is a real scientific finding.
- **Atlas Learning Lab graph**: four model task scores, 72, 74, 73, 76 points on a 0–100 scale. `period` is the fictional week; `value` is model task score.
- **Study-hub population**: 200 synthetic sessions, 100 per studio. `zone` is North/South; `rating` is a model 1–5 score. North repeats 4,5,4,3,5; South repeats 2,3,2,4,3, giving population mean 3.50.
- **Riverlight Park**: 12 synthetic days. `temp` is °C, `group` is Cool/Warm, `visitors` is a model daily count, and `drinks` is fictional iced-drink units sold. Values were deliberately constructed so the overall association is stronger than within temperature strata, making temperature a plausible third-variable explanation.

## Activities
1. **Graph framing:** two views read from the exact same array. The learner changes only the y-axis minimum; values and statistics stay fixed. The copy explicitly avoids teaching that every non-zero axis is deceptive and notes that chart type/context matter.
2. **Sampling:** “Convenience” deliberately includes only North sessions. The less-biased stratified method spans the full alternating population. The 20/40/80 controls demonstrate that adding more observations from an exclusionary method does not make excluded units eligible.
3. **Correlation:** learners filter all/cool/warm days, compare a scatterplot and accessible table, and choose a conclusion. The final fictional headline combines visual framing and volunteer-sample limitations and asks for claim + supporting observation + limitation.

## Feedback, differentiation and model limits
There is no score or penalty. Hints ask what selection rule or causal evidence is missing. Use one case at a time for lower reading load; for extension, ask learners to propose data that would better test a causal question. The sampling and park examples are deterministic teaching models, not estimates of any real population. Correlation coefficients summarize linear association in the synthetic rows only.

## Sources
1. **Office for National Statistics Service Manual — “Axes and gridlines”**  
https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines  
Supports careful axis scaling: bar/area charts need a zero baseline, while some point/line charts can use non-zero starts when clearly framed to show detail.

2. **OpenStax Introductory Statistics — “1.2 Data, Sampling, and Variation in Data and Sampling”**  
https://openstax.org/books/introductory-statistics/pages/1-2-data-sampling-and-variation-in-data-and-sampling  
Supports the distinction between random/systematic approaches, convenience sampling and sampling bias; it informs the lesson’s emphasis that selection method matters.

3. **OpenStax Introductory Statistics 2e — “12.2 Scatter Plots”**  
https://openstax.org/books/introductory-statistics-2e/pages/12-2-scatter-plots  
Supports reading overall scatterplot patterns and deviations. The lesson pairs this with an explicit caution that observational association alone does not establish cause.

## Offline follow-up
Take any published chart. Write down the numeric values you can verify, one presentation choice that affects emphasis, one sampling/design question, and a one-sentence conclusion that does not go beyond the evidence.
